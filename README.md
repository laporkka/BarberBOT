
BarberBOT v1.0.0 💈

BarberBOT — это асинхронное B2B микро-SaaS решение для автоматизации онлайн-записи и управления расписанием в барбершопах. Продукт построен на базе современной контейнеризированной архитектуры, разделяющей ядро бизнес-логики (API) и визуальный интерфейс (Telegram-бот).
Главная технологическая особенность проекта — собственная битовая карта времени (Time Bitmap), обеспечивающая мгновенный расчет и фильтрацию свободных окон без тяжелых и ресурсоемких запросов к базе данных.

🔥 Ключевой функционал по ролям

Бот автоматически распознает Telegram ID пользователя при старте (/start) и разводит его по трем изолированным сценариям использования:

1. 📱 Клиентский интерфейс (Личный кабинет)

• Пошаговое бронирование (CJM): Интуитивный процесс записи (Выбор мастера ➔ Выбор услуги ➔ Динамический календарь на 7 дней ➔ Выбор времени визита).
• Сбор контактов в 1 клик: Безопасная отправка реального номера телефона через нативную reply-кнопку Telegram (request_contact=True).
• Личный кабинет: Просмотр актуальных будущих записей с локализованными статусами визитов на русском языке.
• Интерактивный UX: Полноценная навигация с кнопками «Назад» и «Отмена» на каждом шаге, исключающая тупиковые экраны.
• Прайс-лист: Просмотр списка услуг, их цен и длительности напрямую из базы данных без запуска процесса записи.

2. ✂️ Интерфейс Мастера (Барбера)

• Мобильное расписание: Быстрый просмотр актуального списка клиентов на «Сегодня» и «Завтра» с указанием времени и услуг.
• Авторизация по TG-ID: Мастеру не нужно вводить логины и пароли — система мгновенно сопоставляет его профиль.

3. 📊 Интерфейс Управляющего (Менеджера)

• Контроль загрузки: Просмотр общей картины записей по всему салону.
• Администрирование: Хардкод-защита по списку ADMIN_IDS в конфигурации .env, исключающая несанкционированный доступ к управлению бизнесом.

🛠️ Технологический стек (Architecture & Infrastructure)


Бэкенд (Core API)

• FastAPI: Асинхронный высокопроизводительный веб-фреймворк для реализации REST API. Автоматическая генерация интерактивной документации Swagger.
• SQLAlchemy 2.0 (Async): Современная ORM для работы с базой данных в асинхронном режиме.
• Pydantic v2: Строгая валидация входящих JSON-пакетов и исходящих ответов (Data Integrity).
• Alembic: Изолированная система миграций для контроля версий структуры БД.

Фронтенд (Интерфейс)

• Aiogram 3.x: Передовой асинхронный фреймворк для разработки Telegram-ботов с использованием изолированных Роутеров (Router) и Машины Состояний (FSMContext).
• HTTPX: Асинхронный HTTP-клиент, использующий пул соединений для ультрабыстрой связи бота с FastAPI-бэкендом.

База данных и Инфраструктура

• PostgreSQL: Надежное реляционное хранилище данных.
• Docker & Docker Compose: Полная контейнеризация всех слоев приложения (api, bot, postgres) для мгновенного деплоя на любой Linux-сервер 24/7 одной командой.

🧠 Алгоритм расписания: Побитовые маски (Time Bitmap)

Вместо классических "тяжелых" SQL-запросов с поиском пересечений интервалов времени (BETWEEN), в проекте реализована концепция битовых карт.
1. Рабочий день (с 10:00 до 20:00) разбивается на 20 слотов по 30 минут.
2. Весь рабочий день мастера кодируется в памяти как одно число (Битмап равен 0).
3. Когда клиент бронирует интервал, соответствующие биты дня "включаются" в единицу (bitmap |= (1 << idx)).
4. При поиске окон под новую услугу бот генерирует "Трафарет" (битовую маску длины услуги) и прикладывает её к битмапу дня через операцию Побитового И (&).
5. Если результат равен 0 — интервал абсолютно свободен. Расчет происходит на уровне процессора за наносекунды.

🚀 Быстрый запуск на локальной машине или сервере

Проект полностью готов к развертыванию. Для запуска вам понадобятся только установленные Docker и Docker Compose.

1. Подготовка конфигурации

Создайте файл .env в корневом каталоге проекта и заполните его:
env
# База данных
POSTGRES_USER=postgres
POSTGRES_PASSWORD=your_secure_password
POSTGRES_DB=barber_db
DATABASE_URL=postgresql+asyncpg://postgres:your_secure_password@postgres:5432/barber_db

# Telegram-бот
BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ  # Токен от @BotFather
ADMIN_IDS=["5288382067"]                          # Ваш Telegram ID для прав управляющего
Use code with caution.

2. Запуск инфраструктуры

Выполните команду в терминале:
bash
docker compose up -d --build
Use code with caution.
Docker автоматически скачает образы, создаст изолированную внутреннюю сеть, запустит PostgreSQL, применит миграции базы данных и запустит процессы бэкенда и бота.

3. Проверка работы

• Автоматическая документация бэкенда (Swagger) доступна по адресу: http://localhost:8000/docs
• Telegram-бот готов принимать команды в вашем мессенджере. Напишите ему /start.
